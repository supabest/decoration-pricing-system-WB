# 装修成本智能分析系统 · 同事使用说明

访问地址：https://decoration-pricing-system.pages.dev

---

## 一、注册（首次使用）

1. 打开 https://decoration-pricing-system.pages.dev/#/register
2. 填写：
   - 邮箱（作为登录账号）
   - 密码（不少于 6 位）
   - 昵称（可选，用于显示）
3. 提交后状态为「待审批」，**此时还不能看基准价**
4. 若系统要求邮箱验证，请先到邮箱点击确认链接

## 二、等管理员批准

注册后通知管理员，管理员在 https://decoration-pricing-system.pages.dev/admin.html
→「用户管理」→「待审批」中点「✅ 批准」。

批准后页面右上角显示「已认证」，即可正常使用。

## 三、日常使用

| 步骤 | 说明 |
|------|------|
| 登录 | https://decoration-pricing-system.pages.dev/#/login |
| 套价工具 | 导航栏「套价工具」，或直接打开 `/tool.html` |
| 导入清单 | 支持 Excel BOQ 导入，也可手动新增行 |
| AI 一键套价 | 先在 AI 面板填入**自己的** API Key（DeepSeek 或智谱），再点「✨ AI 一键套价」 |
| 导出 | 「配置导出」生成新表 / 「模板导出」填入公司模板 / 「辅材清单」导出辅材明细 |

### 关于 API Key

- Key 只在本次会话使用，**系统不保存**，下次使用需重新填写
- Key 必须与所选模型厂商匹配（选 DeepSeek 就填 DeepSeek 的 Key）
- 费用由各自 Key 承担

## 四、数据与权限

| 数据 | 权限 |
|------|------|
| 基准价库（497 条） | 全体已认证用户**只读**，仅管理员可改 |
| 材料信息价 | 公开可读 |
| 自己的项目草稿 | 仅本人可见（按账号隔离） |
| 意见反馈 | 可提交，管理员可见 |

## 五、常见问题

**Q：第一次点 AI 套价要等很久？**
后端部署在免费档，闲置会休眠，首次请求冷启动约 45 秒，之后正常。

**Q：AI 套价结果显示「置信度不足」？**
说明该清单项未匹配到合适子目，需手动在基准价库中拖选子目，或在「补缺清单」中反馈给管理员补充。

**Q：看不到基准价侧栏数据？**
检查右上角是否为「已认证」。未审批账号读不到基准价。

**Q：换电脑后历史方案还在吗？**
在。方案保存在云端，按账号隔离，换设备登录即可继续。

## 管理员操作备忘（不发给同事）

- 审批入口：`admin.html` → 用户管理 → 待审批 → 批准
- 设为管理员：全部用户列表 → 「设为管理员」（可审批他人、改基准价、录入信息价）
- 注销：删除用户（不可恢复）
- 拒绝注册：自动删除该用户资料
