## 与远端 JS 口径逐项对照

| 远端函数 | 口径 | WB 实现 | 一致 |
|---|---|---|---|
| `effPrice` | `price × coef × globalCoef(1) × conv` | `price.labor_price` | ✅ |
| `rowUnitPrice` | `Σ effPrice(sub)` | 同上，多子目求和 | ✅ |
| `rowMatCost` | `Σ matPrice×(1+waste/100)×coef×conv` | `price.material_cost` | ✅ |
| `effRowMatPrice` | `Σ matPrice×coef×conv`（净料同基） | `cli` 导出「主材单价」列 | ✅ |
| `effRowWaste` | 由 `主材费÷主材单价−1` 反推并取整 | 同式，`round(...,2)` | ✅ |
| `getAuxDetailForSub` | `fixedK`(无条件) + RATE/GROUP 材料费 | `aux_rules.aux_detail` | ✅ |
| `computeAuxForRow` | `Σ` 各子目，**不乘** coef/conv | `cli._build_subs` 累加 | ✅ |
| `compUnitPrice` | `lab+mat+aux+mgmt+profit` | 内部口径 mgmt/profit = 0 | ✅ |
| `EXP_COLS` | 16 列 + 3 套预设 | 16 列逐字对齐 | ✅ |

**查证结论**：远端内部模式虽写着 mgmt/profit，但 `globalMgmtRate/globalProfitRate` 默认 0；17%/12% 只在集团模式读取。用户「对内不含管理费与利润」的判断成立。

## 合计变化说明

上次基线合计 105,917.61 → 本次 **141,434.80**。差异**不是算错**，来自 P0-3 修正的两处真实 bug：

1. 旧 `_aux_cost` 只在 `rule_type` 含 FIXED 时取 `fixed_k`，RATE/GROUP 规则直接返回 0 → 漏算 63+2 条子目的固定辅材费
2. 旧实现完全没算 `材料信息价 × 消耗量`

修正后与远端 `computeAuxForSub` 一致。
