📥 从 Excel 粘贴材料价格

在 Excel 中选中「材料名称 + 价格」两列（或三列含单位），Ctrl+C 复制，然后在此处 Ctrl+V 粘贴。
格式：材料名称 → 单位 → 价格（Tab 分隔，单位列可选）
